# Next.js + Tailwind CSS + FSD starter

Стартовый проект на Next.js App Router, React, TypeScript и Tailwind CSS с правилами FSD и SVGR.

```bash
bun install --frozen-lockfile
bun run dev
```

Приложение доступно по адресу [localhost:3000](http://localhost:3000).

Инструкции по настройке, командам и структуре проекта находятся в [docs](docs/README.md).
